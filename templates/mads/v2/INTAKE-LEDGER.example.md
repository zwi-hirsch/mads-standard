# §34 result intake — example, not evidence

Before a first task and every restart establish the ledger, freeze all independently observed roots and completed results, and require exact ACK. Preserve old refs/objects; a branch listing alone does not capture deleted or overwritten results.

History roots JSON: schema mads.history-roots.v1, roots array of unique {label, oid} for all canonical/mirror and known old PR/ref/backup commits. Run scripts/intake_history.py --repo PATH --roots ROOTS.json --out NEW.jsonl on a verified complete authorized mirror. Capture real RC, SHA256, all missing roots, independent ref coverage and every parent-edge delta; no GC/prune or unauthorized ref writes. Reconcile old and new object bytes and product state; source inventory is not an acceptance verdict.

Frozen JSON: schema mads.intake.frozen.v1, cycle, main, results list of {id, kind: PRODUCT or EVIDENCE, origin, source:{commit,path,blob}}. Include every result from independently collected inventory, and retain separate artifact occurrences. Ledger JSON: schema mads.intake.ledger.v1, cycle, results list with same id and source, owner, next_action, state, target:{pr,head,tree,blob}, qa:{head,tree,verdict,reviewer,receipt}, merge:{pr,head,commit,main,ancestor_verified,blob} as applicable. Exact source-to-target blob parity is the reference path; transformed changes need a new independently reviewed result. Separate disposition REJECTED/SUPERSEDED/EVIDENCE_ATTACHED uses decision:{commit,blob,owner,reason}, replacement for latter two. Rejected is not merged. An evidence attachment references a product result. Preserve historical decisions, no overwrite.

Observed JSON: schema mads.intake.observed.v1, cycle, start_main, end_main, history_coverage and ref_coverage (INDEPENDENTLY_RECONCILED only after real review), proofs array by id containing independently observed source, target, qa, merge, disposition, decision and replacement as applicable. These are generated by a trusted project adapter or independent reviewer from actual Git/PR/QA/decision evidence, not copied from assessed ledger. Protect the observed and frozen file SHA256 separately from the writer. The reference gate does not authenticate the reviewer or query the server.

Run scripts/intake_gate.py --frozen FROZEN.json --ledger LEDGER.json --observed OBSERVED.json --expected-frozen-sha256 APPROVED --expected-observed-sha256 APPROVED --close. Missing/mismatched/unknown data blocks closure. Without --close, COVERAGE_OK is a partial inventory check only. A new project must independently test adapter and actual restart, result omission, deleted/ref history, conflict/replacement and merge proof before claiming installed gate. No automatic source rights or merge.

Required role report: exact Git result, state/next action, original role and source, target PR, independent acceptance, merged ancestry, missing proof, milestone checkpoints and role LOC; no duplicate imported authorship. If unresolved, INTAKE_ONLY; process existing work, do not issue new research.
